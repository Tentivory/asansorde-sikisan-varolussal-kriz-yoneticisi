# Asansörde Sıkışan Varoluşsal Kriz Yöneticisi

> Resmiyetin dozu kaçmış, asansörün dozu yetmemiş bir kriz yönetim yazılımıdır.

Bu depo, asansör kabininde sıkışan vatandaşın iç dünyasını **ISO belgesiz** ama **tutanaklı** şekilde yönetmek üzere kurulmuştur. Proje bilimsel değildir. Proje felsefi de değildir. Proje sadece asansör durduğunda durmayan tek şeyin saçmalık olduğunu kanıtlar.

## Bu yazılım ne yapar?

1. Asansörün durduğunu varsayar. (Varsaymazsa da varsayar.)
2. Sana resmi bir kriz raporu basar.
3. Teselli eder. Teselli etmez. İkisi birden.
4. Çıkış önermez. Çünkü çıkış asansörün işidir, yazılımın değil.

## Kurulum

Python 3 yeter. Başka hiçbir şey istemez. Asansör bile istemez; hayal gücün yeter.

```bash
python3 kriz.py
```

## Kullanım senaryoları

- Gerçekten asansörde sıkıştıysan: önce 112, sonra bu repo. Öncelik sırası önemlidir.
- Asansörde değilsen: tebrikler, yine de kriz yönetebilirsin.
- Toplantıdasan: bu script toplantıdan daha dürüsttür.

## Mimari

Mimari yoktur. Kabin vardır. Kabinin içinde `random` vardır. `random` evrenin kayyumudur.

```
[ sen ]
   |
   v
[ kriz.py ]
   |
   v
[ resmi görünen saçma tutanak ]
   |
   v
[ kapılar hâlâ kapalı ]
```
